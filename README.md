# 🪔 Diwali Mahotsav Mela - Festival of Lights Interactive Web Game

A vibrant, royal Indian festive celebration web game built with **React**, **HTML5 Canvas (60FPS)**, **Procedural Web Audio API**, and **Real-Time Multiplayer (WebRTC + BroadcastChannel)**.

---

## ✨ Features

- **🎆 Shri Ganesh Patakha Bhandar (पटाखा दुकान)**:
  - Buy traditional firecrackers: *Phuljhadi (फुलझड़ी)*, *Chakri (चकरी)*, *Anar (अनार)*, *Sky Rocket (रॉकेट)*, *Patakha Ladi (लड़ी)*, *Sutli Bomb (सुतली बम)*, *Multi-Shot Peacock Fountain*, and *Laxmi Bomb*.
  - Realistic physics particles with gravity, bounce, smoke rings, and luminous shockwaves.
  - 100% procedural Web Audio synthesizer (whistles, sparks, sub-bass booms, temple bells).

- **🎡 Carnival Attractions & Minigames**:
  - **Mela Giant Wheel (झूला)**: Rideable rotating Ferris wheel with panoramic sky camera.
  - **Balloon Shooting Stall (गुब्बारा निशानेबाजी)**: Carnival cork rifle minigame with scoring and golden balloon bonuses.
  - **Diwali Fortune Spin (धन चक्र)**: Lakshmi fortune wheel awarding festive coins and firecracker bundles.
  - **Sharma Ji Chai Tapri (चाय टपरी)**: Steaming hot Kulhad Chai, Garam Samosa, and roasted Bhutta.
  - **Radhey Sweets Corner (मिठाई दुकान)**: Authentic Diwali sweets (Kaju Katli, Garam Jalebi, Gulab Jamun, Motichoor Laddoo) granting speed buffs and golden auras.
  - **Lakshmi-Ganesh Mandir (मंदिर)**: Interactive temple bell with harmonic ringing and auspicious Shagun blessings.

- **🌐 Real-Time Multiplayer & Social**:
  - **WebRTC PeerJS & BroadcastChannel**: Celebrate with real friends across tabs, local networks, or shared room links (`?room=...`).
  - **Overhead Speech Bubbles**: Comic-style speech bubbles appearing over characters in the 2D world.
  - **Live Chat Drawer**: Quick festive greetings and custom chatting.
  - **Festive Entrance Announcements**: Golden glowing popup toasts whenever any player enters the Mela.
  - **Custom Avatars**: Choose your name, Kurta/Saree festive colors, and Royal Pagri/Turban.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```

---

## 🛠️ Tech Stack
- **Framework**: React 18
- **Bundler**: Vite
- **Rendering**: HTML5 2D Canvas (Custom 60FPS particle & world rendering engine)
- **Audio**: Web Audio API (Zero external audio file dependencies)
- **Multiplayer**: PeerJS (WebRTC) + BroadcastChannel API
- **Icons**: Lucide React
- **Confetti**: Canvas-Confetti
